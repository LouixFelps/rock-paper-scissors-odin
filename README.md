# rock-paper-scissors-odin
A rock paper scissors game

instructions:

1. When you open the html file, it will asks if you want to play
2. If you confirm, than you can play by choosing between rock, paper or scissors
3. When you put your result, than it will tell you if you win or lose
4. If you want to play again, it's just confirm again.

If you clicked "Cancel", than reload the page to play the game.
